# Security policy

## Supported versions

Security fixes are applied to the latest release on the default branch. Pre-1.0
interfaces may change as part of a fix.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use
[GitHub private vulnerability reporting](https://github.com/asguinea/gaussweave/security/advisories/new)
and include affected versions, impact, reproduction steps, and any suggested
mitigation.

You should receive an acknowledgement within seven days. Please allow time to
investigate and coordinate a fix before disclosing the issue publicly.
